# Режим Create — полная документация Kaplao

Режим **Create** (`HostGameMode.Create`) — редактор уровня. Доступен игроку с ролью **Kaplao** (курсор-хост). В этом режиме расставляются и редактируются тайлы, настраиваются группы, текстуры, частицы, keyframe-маркеры, executor'ы и параметры мира.

> Документация по режиму **Code** (скрипты) — отдельно, здесь не описывается.

## Вход в режим

1. Зайти в мир как игрок **Kaplao**.
2. В верхней панели нажать **Create**.
3. Режим переключается на сервере (`KaplaoCursorServer.SetHostGameMode`). UI реагирует сразу через `KaplaoLocalGameModePredictor` (предсказание до ответа сервера).

**При входе в Create:**
- Выделение и grab-состояние сбрасываются.
- Открытые редакторы (executor и др.) закрываются с сохранением.
- Инструмент **Grab** автоматически заменяется на **Select**.
- Показывается системный курсор ОС.
- Включаются оверлеи сетки, координат, цветовой панели.

**При выходе из Create** (Usual / Code):
- Панели Create скрываются.
- Selection toolbar и открытые панели закрываются.

| Клавиша | Инструмент | Тип тайла | Назначение |
|---------|------------|-----------|------------|
| `1` | **Select** | — | Выделение, трансформация, клик по раннерам |
| `2` | **Block** | `TileType.Block` | Блок |

Дополнительно для шипа:

## Размещение и удаление тайлов

### Размещение (инструменты 2–4, 6–8)

- Тайлы ставятся **по сетке** 1×1 (центр ячейки).
- Превью на курсоре привязано к сетке.
- **Обычный клик ЛКМ** — одна установка при отпускании (не после панорамирования камеры).
- **Shift + зажатая ЛКМ** — непрерывная «кисть» по ячейкам при перетаскивании.
- В одну ячейку **на одном editor layer** нельзя поставить два тайла.
- Цвет нового тайла берётся из **панели цвета** (`KaplaoTileColorState.PlaceColor`).
- Слой размещения: активный editor layer, если выбран конкретный слой; иначе слой **0**.
- Каждое размещение/удаление попадает в **undo**.

### Удаление (инструмент 5)

- **Клик ЛКМ** — удаляет **один** верхний тайл под курсором.
- **Shift + зажатая ЛКМ** — непрерывное удаление при проведении.
- Прямоугольник marquee при удалении **не показывается**.

## Выделение

Инструмент **Select** (`1`).

| Действие | Результат |
|----------|-----------|
| Клик по тайлу | Выделить верхний тайл под курсором |
| Повторный клик в той же точке | Циклически переключить между перекрывающимися тайлами |
| `Ctrl` + клик | Добавить к выделению (с учётом link-группы) |
| `Shift` + перетаскивание | Прямоугольное выделение (marquee) |
| `Shift` + `Ctrl` + перетаскивание | Добавить тайлы из прямоугольника |
| Клик по пустому месту | Снять выделение |
| Клик по **раннеру** | Открыть панель **Promote Runner** (нельзя для admin-раннеров) |

**Связанные тайлы:** при выделении одного тайла автоматически выделяются все связанные с ним (`LevelGridServer.ExpandSelectionWithLinks`).

**Фильтр выделения:** тайлы, не проходящие `CreateModeSelectionFilter`, не выделяются. Тайлы на другом editor layer (когда выбран конкретный слой) недоступны. Тайлы, участвующие в активной анимации скрипта, недоступны.

При выделении появляется **Selection HUD** с количеством объектов, слоями, группами, sorting order и подсказкой `G - move / R - rotate / T - scale`.

## Трансформация (G / R / T)

Работает при **Select** + ненулевом выделении. Не работает, если фокус в текстовом поле.

| Клавиша | Режим | Описание |
|---------|-------|----------|
| `G` | Move | Перемещение группы |
| `R` | Rotate | Поворот вокруг центра выделения (pivot) |
| `T` | Scale | Масштаб (X и Y с одним коэффициентом) |

### Подтверждение

| Действие | Клавиша |
|----------|---------|
| Применить | **ЛКМ** (отпускание) |
| Отменить | **ПКМ** (отпускание) |

### Ограничение по оси (во время трансформации)

| Клавиша | Эффект |
|---------|--------|
| `X` | Только ось X |
| `Y` | Только ось Y |

Для масштаба без оси X/Y меняются **пропорционально** (один множитель).

Шаги привязки берутся из **Create Settings** (округление видно сразу при движении мыши).

При повороте (`R`) показывается жёлтая линия от центра выделения к курсору.

При выделении, **вне** активной трансформации G/R/T:

| Клавиши | Действие | Шаг |
|---------|----------|-----|
| `W` `A` `S` `D` | Сдвиг выделения | 1.0 |

| `Ctrl` + `C` | Копировать в буфер | — |
| `Ctrl` + `V` | Вставить в центр экрана | — |
| `Ctrl` + `Z` | Undo | до 64 шагов |
| `Delete` / `Backspace` | Удалить выделение | — |

## Settings — свойства тайла

Кнопка **Settings** в toolbar.

### Для любого выделения

| Поле | Описание |
|------|----------|
| **Transparency** | Прозрачность 0…1 |
| **No Hitbox** | Отключить коллайдер |
| **Position X / Y** | Позиция в мире |
| **Rotation** | Угол в градусах |

| **Sorting Order** | Порядок отрисовки (-10…10) |

Изменения применяются при подтверждении поля (`onEndEdit`) или переключении toggle.

Значения из панели **не округляются** по шагам Create Settings.

### Только для одного Trigger

| Поле | Описание |
|------|----------|
| **Spawn Point** | Триггер работает как точка спавна для своих групп |

### Read-only

| Поле | Описание |
|------|----------|
| **Created At** | Время создания тайла (Unix ms), если сохранено |

## Группы (Set Group)

Кнопка **Set Group**.

| Элемент | Назначение |
|---------|------------|
| Поле номера группы | Ввод ID группы |
| **Next Free** | Следующий свободный номер группы |
| **<** / **>** | Уменьшить / увеличить номер |
| **Add** | Добавить группу всем выделенным тайлам |
| **Close** | Закрыть панель |
| Чипы групп | Синий = на всех выделенных; тёмный = на части; клик снимает группу |

Группы используются в Level Script: `Group(N)`, executor, keyframe, триггеры.

## Слои редактора (Editor Layer)

Переключатель слоёв в toolbar (**Prev / Next** + метка).

| Метка | Значение |
|-------|----------|
| **All** | Слой -1: фильтр выключен, новые тайлы на слое 0 |
| `0`…`100` | Активный слой: видны/выделяются только тайлы этого слоя |

Логика переключения:
- Из **All**: Prev → 100, Next → 0
- Из **0**: Prev → All
- Из **100**: Next → All
- Иначе: ±1

Слой отдельного тайла задаётся в **Settings → Editor Layer**.

`EditorLayerVisuals` подсвечивает тайлы на активном слое.

---

## Связи тайлов (Link / Unlink)

- **Link** — жёстко связывает ≥2 выделенных тайла (двигаются вместе при трансформации).
- **Unlink** — разрывает связи у выделения.
- Связи сохраняются при копировании, вставке, дублировании и в `level.json` (`linkGroups`).

## Цвет тайлов

Панель **TileColorPanel** (левый нижний угол, всегда видна в Create).

- HSV-область + полоска оттенка
- Слайдеры **R / G / B** (0–255)
- Поле **hex** (`RRGGBB`)
- Быстрые пресеты

Выбранный цвет применяется к **новым** тайлам и к **уже выделенным** (если есть выделение).

Панель в сцене: `CreateModeUI/TileColorPanel`. Пересоздать: **Kaplao → Setup Tile Color Panel** или **Kaplao → Setup Create Mode UI**.

## Текстуры

### Применение

Кнопка **Set Texture** → панель с поиском, превью и названиями. Клик применяет текстуру к выделенным **Block** и **Spike**.

### Импорт кастомных текстур

Кнопка **Import Texture** (в Create, на сервере):
- Имя + PNG-файл → регистрация в мире (тайлы не создаются).
- В пикере текстур можно переименовать кастомные текстуры.

Каталог блоков Minecraft настраивается в Unity: **Kaplao → Block Textures**.

## Редактор частиц (Particle)

Кнопка **Edit Particles** (если в выделении есть `TileType.Particle`).

Вкладки **Motion** и **Visual**. Изменения применяются в реальном времени с превью.

### Motion

| Поле | Описание |
|------|----------|
| Duration | Длительность |
| Lifetime | Время жизни (value + range) |
| Emission | Частота эмиссии |
| Angle | Угол разлёта |
| Speed | Скорость |
| Pos Var X/Y | Разброс позиции |
| Gravity X/Y | Гравитация |
| Accel Rad / Tan | Радиальное / тангенциальное ускорение |

### Visual

| Поле | Описание |
|------|----------|
| Start/End Size | Размер |
| Start/End Spin | Вращение |
| Start/End R/G/B/A | Цвет и альфа (value + range) |
| Texture | ID текстуры частицы |

При мультивыделении пустые поля = «не менять»; патчатся только изменённые значения.

## Импорт и экспорт

### Level JSON (Level IO)

Панель **LevelIoPanel**: **Import** / **Export**.

| Действие | Кто | Описание |
|----------|-----|----------|
| Import | Kaplao | Загрузить `.json`, заменить уровень на сервере |
| Export | **Только host** | `ExportLevelData()` → файл `.json` |

Формат `LevelData` (версия 10): script, tiles, linkGroups, worldSpawn, bannedIds, bannedIps и др.

### PNG → тайлы

**Import PNG** (Create, server):
- Поля `tiles X` / `tiles Y` (по умолчанию 10×10)
- Выбор PNG → создаёт цветные **Block** в центре экрана (без текстур, только цвет пикселей)

### Кастомные текстуры и звуки

- **Import Texture** — PNG в каталог мира
- **Import Sound** — кнопка может быть скрыта (`HideOpenButtonForNow`); загрузка `.ogg` и др. на сервер в Create

## Ограничения и host-only

| Функция | Ограничение |
|---------|-------------|
| Export level JSON | Только host |
| Import level / PNG / texture / sound | Сервер, режим Create |
| Все мутации тайлов | Роль Kaplao |
| Promote runner | Нельзя для admin-раннеров |
| Level Settings (world spawn, runner collision) | Host + Kaplao + Create (кнопка может быть скрыта) |
| Selection filter panel | Кнопка может быть скрыта; фильтр в коде поддерживается |

Модераторы и баны — отдельная система (`LevelSessionServer`), не часть Create UI.
